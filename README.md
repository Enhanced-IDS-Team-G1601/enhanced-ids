# Enhanced-IDS

An explainable intrusion detection system for network security.

## Project Overview

This project classifies network traffic as normal or suspicious using deep learning and explainable AI.

## Datasets

- NSL-KDD
- CICIDS 2017

## Architecture

Data Preprocessing
→ Feature Selection
→ CNN
→ BiGRU
→ Attention
→ Classification
→ SHAP Explainability

## Project Structure

- `datasets/` - Dataset files
- `notebooks/` - Jupyter notebooks
- `src/` - Source code
- `models/` - Trained models
- `results/` - Results and plots
- `app/` - Application
